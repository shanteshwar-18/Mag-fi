This directory contains the pre-packaged SQLite database used by SQLiteAssetHelper.

REQUIRED FILE:
  map_database.db — generated by the Python Bridge (Phase 1) from raw_mapping CSV.

The EXACT path must be:
  app/src/main/assets/databases/map_database.db

SQLiteAssetHelper reads ONLY from this specific subfolder.
Do NOT rename this directory or the file extension.
